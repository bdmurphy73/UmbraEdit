Coming from novelWriter
=======================

Overview
========

What it is
    A guide for existing novelWriter users transitioning to UmbraEdit.

What it does
    Explains what stays the same, what changes, and how to open an
    existing novelWriter project.

Before you start
================

You need a working novelWriter project. UmbraEdit can open it directly.

What stays the same
===================

* The project format (``nwProject.nwx``) is unchanged.
* Documents are still plain text with the same formatting syntax.
* Tags, references, and keywords work the same way.
* The project tree, editor, and manuscript build tools work the same way.

What changes
============

* The application is called **UmbraEdit** instead of **novelWriter**.
* The package name is ``umbraedit`` instead of ``novelwriter``.
* Translation files use the ``ue_`` prefix instead of ``nw_``.
* New features (multi-language publishing, text-to-speech, asset store)
  are added. Your existing text is not affected.
* The splash screen and icons are different.

Opening a novelWriter project
=============================

1. Launch UmbraEdit.
2. Click **Browse** in the Welcome dialog.
3. Navigate to your existing project folder.
4. Select the ``nwProject.nwx`` file.
5. Click **Open**.

The project opens with all your text and notes intact.
