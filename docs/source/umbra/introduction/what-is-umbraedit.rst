What is UmbraEdit?
==================

Overview
========

What it is
    UmbraEdit is a plain text editor designed for writing novels
    assembled from many smaller text documents. It uses a minimal
    formatting syntax inspired by Markdown, and adds a meta data
    syntax for comments, synopsis, and cross-referencing.

What it does
    UmbraEdit lets you write a novel as a collection of plain text
    documents organised in a project tree. Each document is a single
    scene, chapter, or note. The project format is well suited both
    for version control software and file synchronisation tools.

    UmbraEdit extends the proven novelWriter workflow with features
    for multi-language publishing, text-to-speech, and machine-assisted
    review.

Why it exists
    UmbraEdit exists to make long-form manuscript writing simpler by
    keeping everything in one project: the novel text, character
    information, settings, publishing metadata, and audio production
    data. At the end of the process you will have EPUB, print-ready
    PDF, and audio versions.

Before you start
================

You do not need any prior experience with plain text editors or
Markdown-style formatting.

Quick start
===========

1. Download and install UmbraEdit (see :doc:`installation`).
2. Create a new project from the Welcome dialog.
3. Start writing in the editor.
