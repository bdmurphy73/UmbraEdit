First Book
==========

Overview
========

What it is
    A step-by-step tutorial for creating your first book in UmbraEdit.

What it does
    Walks you through creating a project, adding characters, writing
    scenes, and building a manuscript.

Why it exists
    To get you writing as quickly as possible.

Before you start
================

You need UmbraEdit installed (see :doc:`installation`).

Quick start
===========

1. Launch UmbraEdit. The Welcome dialog appears.
2. Click **New** to create a new project.
3. Enter a project name (for example, "My Novel") and click **Create**.
4. Click the **+** button above the project tree to add a new document.
5. Type your first scene. Use ``### Scene Title`` for a heading.
6. Add a character with ``@char: firstname`` on a line before the text.
7. Press **F5** to open the Manuscript Build tool.
8. Select which documents to include and click **Build**.
9. Choose a format (HTML, DOCX, EPUB) and an output location.
10. Click **Build** to produce the output file.

Tasks
=====

Add a character
    1. Click the **+** button above the project tree.
    2. Choose **New Character** from the menu.
    3. Enter the character name and click **OK**.
    4. Write a description in the note editor.

Write a scene
    1. Add a new document to the Novel root.
    2. Start with ``### Scene Title``.
    3. Write your text below the heading.
    4. Use ``**bold**`` and ``_italics_`` for emphasis.

Build a manuscript
    See :doc:`/umbra/writing/manuscript-build`.

Messages and checks
===================

UmbraEdit checks your project before building. If a check fails, you
will see a message explaining what is wrong and how to fix it.
