## Tags

Any document or note can be given a tag that you can reference from another document or note. These tags have to be unique across the entire project. You can define a new tag for each heading in a document.

In this scene, the tag `@tag: Scene.Tags` is defined at the top. You can reference this tag from any other document in the project.

## Reference Keywords

UmbraEdit supports several reference keywords for cross-referencing:

- `@pov: Name` — Point of View character
- `@char: Name` — Character reference
- `@location: Name` — Location reference
- `@mention: Name` — General mention

In this scene:
- `@pov: Narrator` — the story is told from the narrator's perspective
- `@char: Jane, John` — characters Jane and John appear in this scene
- `@location: Earth` — the scene takes place on Earth

You can click Ctrl+Enter with the cursor on top of a reference to see the content of the file the reference points to. In the view pane, all references are clickable.
