## Chapter 4: Character Examples

This chapter demonstrates how UmbraEdit handles character references: POV references, character references, location references, and mentions.

### Scenes in This Chapter

- Scene 4.1: POV References — @pov keyword
- Scene 4.2: Location References — @location keyword

## What You'll Learn

By the end of this chapter, you will know how to:
- Set POV characters for scenes
- Reference characters in scenes
- Reference locations in scenes
- Use mentions for general references
