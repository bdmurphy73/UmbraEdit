# Introduction

Welcome to the UmbraEdit Sample Project. This project demonstrates every feature available in UmbraEdit, from basic text formatting to advanced story structure, character references, comments, footnotes, and more.

## What is UmbraEdit?

UmbraEdit is a plain text editor for planning and writing novels. It organizes your work into small documents (one per scene) organized in a tree structure. You write in a minimal Markdown-like syntax, and UmbraEdit handles the formatting when you export or build your manuscript.

## How to Use This Project

Open this project in UmbraEdit and browse through the chapters in the tree view on the left. Each document demonstrates a specific feature:

- **Chapter 1** demonstrates text formatting, shortcodes, lists, links, and alignment
- **Chapter 2** demonstrates story structure (chapters, parts, sections), tags, and cross-references
- **Chapter 3** demonstrates story comments, note comments, and footnotes
- **Chapter 4** demonstrates POV references and location references
- **Characters** folder shows character sheets with tags and references
- **Worlds** folder shows location sheets
- **Archive** shows how to store old scenes
- **Templates** shows reusable document templates
