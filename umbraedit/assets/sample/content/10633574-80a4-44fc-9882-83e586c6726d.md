## Using Sections

If you need to split a scene file up into further pieces, you can do so with the level four heading, like the one above this paragraph. This is referred to as a “section” in the documentation.

Both scene and section titles can be left out of the final exported document. The formatting of titles can be selected from the Build Manuscript tool. You can also have them replaced with scene separators like “* * *”.

## When to Use Sections

Use sections when:
- You want to keep related content in one document
- You need logical subdivisions within a scene
- You want to apply different formatting to different parts of a scene

Use separate scene documents when:
- The content represents a distinct scene in your story
- You want to track word count separately for each scene
- You need different POV or character assignments
