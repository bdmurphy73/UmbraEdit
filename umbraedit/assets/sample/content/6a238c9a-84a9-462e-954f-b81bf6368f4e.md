### Scene 1.3: Lists and Links

@tag: Scene.ListsLinks
@pov: Narrator

## Bullet Lists

You can create single-level bullet lists using a `*` and a space:

* List item 1
* List item 2
* List item 3

## Ordered Lists

Ordered lists use the `#.` notation:

#. List item 1
#. List item 2
#. List item 3

## Links

You can add URLs with custom link text:

[Example Website](http://www.example.com)

[UmbraEdit on GitHub](https://github.com/bdmurphy73/UmbraEdit)

[UmbraEdit Releases](https://github.com/bdmurphy73/UmbraEdit/releases)

You can also link to other documents in your project using reference keywords like `@char`, `@pov`, `@location`, and `@mention`. See Chapter 2 and Chapter 4 for examples.

## Mixed Example

Here is a list that combines different features:

* First item with **bold** text
* Second item with _italic_ text
* Third item with a [link](https://github.com/bdmurphy73/UmbraEdit)
