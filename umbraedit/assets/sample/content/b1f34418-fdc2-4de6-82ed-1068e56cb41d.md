## Chapter 1: Basic Formatting

This chapter demonstrates all basic text formatting features available in UmbraEdit. Each scene below covers a different aspect of text formatting.

### Scenes in This Chapter

- Scene 1.1: Text Emphasis (bold, italic, strike, quotes)
- Scene 1.2: Shortcodes (superscript, subscript, partial bold, underline, highlight)
- Scene 1.3: Lists and Links (bullet lists, ordered lists, URLs)
- Scene 1.4: Text Alignment and Indentation

## What You'll Learn

By the end of this chapter, you will know how to:
- Apply bold, italic, bold-italic, and strike-through formatting
- Use shortcodes for superscript, subscript, underline, highlight, and partial formatting
- Create bullet and ordered lists
- Add URLs with custom link text
- Align text left, right, center, or indent paragraphs
